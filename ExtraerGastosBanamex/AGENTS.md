## Architecture

- **Pattern**: Single process workflow with sequential browser, Excel, and WhatsApp stages.
- **Data flow**: Banamex expense export → downloaded file opened in Excel → `SUMA(D:D)` entered in F1 → F1 read into `totalCompras` → formatted WhatsApp message.
- **Execution flow**: Open/navigate Banamex → retrieve credentials and sign in → export report → attach to Excel and calculate/read total → if numeric, send WhatsApp message; otherwise log a warning.
- **External integrations**: Banamex/BancaNet in Microsoft Edge, Microsoft Excel, WhatsApp Web, and an Orchestrator credential asset.
